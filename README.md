Сервис хранит пользовательские файлы в MinIO, а учётные записи — в PostgreSQL.
Backend написан на Spring Boot и предоставляет REST API для регистрации, входа, загрузки, скачивания, поиска, переноса и удаления файлов.
Файлы каждого пользователя хранятся отдельно.
Redis используется для сессий и кэширования, а Kafka передаёт события о крупных загрузках.
Отдельный notification-service получает события Kafka и отправляет почтовые уведомления.
Настройки почты задаются в локальном файле `.env`, который создаётся копированием `.env.example`.
Для сборки и запуска выполните `docker compose up -d --build` из каталога проекта; backend доступен на порту 8080, MinIO — на порту 9000, а его консоль — на порту 9090.
